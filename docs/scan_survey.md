# スキャン調査の結果（数値のみ）

作業環境に PyMuPDF が入れられなかったため、`tools/survey_scans.py` と同じ解析関数（`analyze_pixels`、PageAnalyzer と同じしきい値）を poppler（pdftoppm / pdfimages / pdftotext）＋ pikepdf から呼ぶ形で実行した。画像は含まない。

- 漫画（ジョジョ 63 冊）は 2 ページに 1 ページ＋横長ページ全部を長辺 600px で解析。それ以外の PDF は 8 ページに 1 ページ
- `ジョジョテスト` フォルダの元 PDF（`ジョジョの奇妙な冒険` フォルダと同じファイル）と、0 バイトの `_fixed.pdf` は対象外。`_fixed.pdf` は第10巻の 1 冊だけ見本として解析
- JSON の各ページの `analysis` には survey_scans.py の項目に加えて `border_luma`（外周 3% の帯の平均の明るさ）、`white_margin`（白い余白の割合）、`skew_deg`（参考値。ジョジョは斜めのコマが多く当てにならない）、`ink_fraction`、`blank`、`dhash_dist_prev`（前ページとの似かより）、横長ページの `gutter`、一部の `osd`（tesseract の向き推定。漫画では信頼度が低く使えない）がある
