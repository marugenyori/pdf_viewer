## 調べてほしいこと

### A. 全体（フォルダ全体）

1. ファイルの種類と数：PDF 以外（JPEG、ZIP など）も混ざっていないか
2. フォルダの分け方：作品ごとのサブフォルダがあるか。ファイル名の付け方（巻数の書き方など）
3. 1冊のページ数と、ファイルサイズ（最小・中央・最大）
4. iCloud にしかない（PC にダウンロードされていない）ファイルがどれくらいあるか

### B. PDF の作り（何冊か開いて）

5. 1ページ＝1枚の画像か。画像の形式（JPEG / JBIG2 など）、色（カラー / グレー / 白黒2値）、解像度（dpi）
6. 文字が検索できる PDF（OCR の文字情報入り）か
7. ページの大きさがそろっているか。横長のページはどれくらいあるか
8. PDF の回転指定（`/Rotate`）が使われているか

### C. 見た目の問題（ページを画像にして実際に見る）

9. **回転**：横向き・逆さまのページはどれくらいあるか。90° / 180° / 270° のどれが多いか。数度の傾きもあるか。
   回転の原因は、PDF の `/Rotate` の指定か、画像そのものが回っているのか
10. **横長のページの正体**：横向きにスキャンされた1ページなのか、見開きの2ページを1枚にスキャンしたものなのか（**いちばん知りたい点**）
11. **色・明るさ**：紙の黄ばみ、ページごとの濃さの違い、裏写り。カラーのページはどれくらいあるか（表紙・口絵だけか）
12. **縁と余白**：スキャン範囲の外の黒い帯や影はあるか。色（真っ黒 / 灰色 / グラデーション）と、だいたいの幅。白い余白の広さ
13. そのほか気づいたこと（ページの抜け・重複、順番の乱れ、白紙のページ、ゴミや指の写り込み、モアレなど）

## 調べ方の例

```powershell
git clone https://github.com/marugenyori/pdf_viewer.git
cd pdf_viewer
pip install pymupdf numpy
$env:PYTHONUTF8 = "1"
python tools/survey_scans.py "C:\Users\yfb31\Documents\icloud同期フォルダ\iCloudDrive\ScanSnap Home" --samples "$env:USERPROFILE\Desktop\scan_samples"
```

- `tools/survey_scans.py` は、1冊あたり 8 ページを長辺 600px の画像にして、黒い縁の幅・紙の色・カラーかどうか・埋め込み画像の形式と dpi を数値にします。結果は `docs/scan_survey.md`（要約）と `docs/scan_survey.json` に出ます
- 見本の PNG はデスクトップの `scan_samples` に保存されます。**数値だけでなく、何枚かは実際に画像を開いて目で確かめてください**（特に C の 9〜12）
- スクリプトを使わず、自分のやり方で調べてもかまいません
- iCloud にしかないファイルは、開くとダウンロードされるので時間がかかります。先に ScanSnap Home フォルダを右クリック →「このデバイス上に常に保持する」にしておくと早く進みます

## 守ってほしいこと

- **PDF の中身や見本画像は、リポジトリにも報告書にも入れない**（市販の漫画のスキャンで、著作物のため）。報告書は文章と数値だけにする
- ファイル名（書名）は報告書に書いてかまいません（リポジトリは非公開）
- 元のファイルは変更・移動・削除しない（読むだけ）

## 報告のしかた

1. 下の「報告書」の各項目を埋める（A〜C の番号に合わせる。わからなかった項目は「不明」と書く）
2. 典型的なページの様子を、言葉で 3〜5 例書く（例：「横長。左右に 2 ページ分。中央にのどの影。上下に 5% ほどの黒い帯」）
3. 「アプリにほしい補正」を、見た結果から優先順に書く
4. このファイルと `docs/scan_survey.*` をコミットして `main` に push する（`git status` で画像や PDF が混ざっていないことを確かめてから）

### アプリにほしい補正（優先順）

1. **横向きページの自動回転（90°/270°）**：横長（2ページ目以降）は必ず 1 ページなので、90° か 270° のどちらかを決めるだけでよい。向きは本の中でも混ざるため、「本のほかのページに合わせる」は使わず、ページごとに判定する。決められないときは 90° にして、すぐ手で回せるボタンを出す（手で回した結果を覚える）。縦長ページの 180° 判定は、ほぼ不要（やるならオフにできるように）
2. **1 ページ目＝カバーの扱い**：横長の 1 ページ目は「カバー全体」として本棚の表紙に使う（右側の表表紙だけ切り出すとよい）。読む画面では飛ばすか、1 枚の横長として見せる
3. **白黒ページの色の補正**：紙→白、インク→黒への引き伸ばしは今のままでよいが、**白黒のページはグレーにしてしまう**（黄ばみの残りを消す）。カラー判定は「紙色で引き伸ばした後の彩度」だけだと黄ばみの強い本で誤判定するので、しきい値を上げるか、「本の最初の数ページ以外は白黒」とみなす設定があるとよい
4. **コントラスト（インクを黒く）**：インクが 0.24 前後と薄いので、黒側の引き伸ばしを強めに
5. **黒い縁・余白の削り**：ほぼ不要。今の処理（85% 暗い行を削る、余白を内側へ）でも害はないが、効果は小さい。紙詰まりページの白い三角は削れないので、そのまま表示でよい
6. **巻数の取り方**：ファイル名の「第N巻」から数字で並べる（名前順だと 1,10,11,… になる）。取れない本は名前順の最後に置く
7. （おまけ）「ジョジョテスト」の重複と 0 バイトの `_fixed.pdf` を本棚に出さない（0 バイトのファイルや、同じ中身の重複を除外する）
